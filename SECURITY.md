# Security Policy

## Reporting a vulnerability

Please report security vulnerabilities privately by email to
**security@symbiosika.de**. Do not open a public GitHub issue for a
vulnerability.

Include, where possible:

- the affected version or commit,
- a description of the issue and its impact,
- steps or a test that reproduce it,
- a proposed fix, if you have one.

We acknowledge reports within a few working days and keep you informed while
we work on a fix.

## Supported versions

Security fixes land on the `develop` branch and ship with the next release of
the `symbiosika-framework` package. Older releases are not patched.
